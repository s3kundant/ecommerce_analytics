# Аналитика e-commerce платформы Olist: динамика метрик, когортный анализ и RFM-сегментация

Комплексный аналитический проект по исследованию транзакционных данных бразильского маркетплейса **Olist** (~100 тыс. заказов за 2016–2018 гг.). Проект охватывает полный цикл работы с данными: проектирование реляционной схемы, автоматизацию загрузки данных в PostgreSQL через Python, расчет продуктовых метрик с помощью SQL-оконных функций, когортный анализ удержания и RFM-сегментацию клиентской базы.

---

## Архитектура и стек технологий

* **База данных:** PostgreSQL 15, реляционная модель в третьей нормальной форме (`users`, `orders`, `order_items`).
* **ETL и обработка данных:** Python 3, pandas, SQLAlchemy, psycopg2.
* **SQL-аналитика:** Оконные функции (`OVER`, `LAG`, скользящие агрегации), фильтрация агрегатов (`FILTER`, `CASE WHEN`), сложные CTE.
* **Визуализация:** Matplotlib, Seaborn, Yandex DataLens.
